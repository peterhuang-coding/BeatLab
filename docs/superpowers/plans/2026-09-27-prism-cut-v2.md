# 尘里有金 v2 · 更丰富的编排与清晰伴奏

用户反馈：可以更复杂，整体不必都 lo-fi。本轮直接实施一版修订，保留 v1。理解为增加可辨识的发展、声部回应、节奏变化和现代伴奏的清晰度，不把噪声或轨数当作复杂度。

## 制作方案

保留三份历史录音的10个实际切片作为主题，增加已有 Core Library 的 Grand Piano C3 f、Vibraphone C3 和 Clap Layered；主旋律/人声仍为录音裁切。升调老录音只占部分音色，鼓、钢琴、低频不再沿用暗色低通设置。相较纯加密鼓组或整体抬高高频，采用声部接力与段落反差，避免把唱片底噪一起放大。

92 BPM、20小节，同 v1 时长。结构改为2小节开场、6小节A、2小节钢琴抽空、6小节B、4小节回归；钢琴在采样空隙回应，B段变化鼓感，终段前有明确留白。和声跟随切片的低音解释，不能把自动分析当作确定调性。最终试听仍由用户判断。
