建议先服务想录歌的独立说唱／旋律说唱音乐人，做 1–3 首同一审美的非独家 beat，验证一位真实买家能完成购买、拿到约定文件并用于录歌。现阶段最缺的是实际试唱、可授予买家的使用范围和真实交易验证；增加采样数量、开更多店铺不能代替这些结果。

## 买家为什么买，以及首个商品是什么

以下是待访谈假设，不是已有市场结论：目标买家已经准备写一首歌，希望找到能激发主题、主歌可录人声、授权看得懂、混音师拿到就能用的伴奏。我们当前老歌翻采的特点可以保留，复杂度放在段落呼应、鼓变化、桥段和副歌，不让完整唱句持续占据两段主歌。

先选一首候选；通过后最多扩到三首。Windowlight / Dust Letters 可作用户认可的音乐方向参考，Afterglow v3 可作多源采样参考；三者都要分别通过来源和商品验收，旧好评不等于新商品已批准。

| 产物 | 用途与建议内容 | 目前缺口 |
|---|---|---|
| 展示版 | 保留采样创意；30–45 秒重点片段 + 完整带制作人水印试听；标题、BPM、调性、情绪、段落入口 | 人工选片、耳听确认调性、实际水印、成品封面与商店文案 |
| 留人声空间版 | 至少一段可录 16 小节主歌；切片回应放句间，hook 保留辨识度 | 需要真实试唱；不能简单把所有轨一并调小，v3 此版尚未制作 |
| 基础非独家许可 | 未加水印 MP3 + WAV + 与该版本对应的授权合同 | 使用范围、署名、作品/录音权及协作分成、期限/地域/用量限制要明确 |
| 分轨非独家许可 | 基础文件 + 同起点/同长度的歌曲分轨 ZIP；优先 kick/snare/hats/bass/music/vocal 等有意义的组 | 用具体清单说明是组分轨还是逐轨；逐首核验可向买家交付的第三方内容 |
| MIDI / ALS / ChopRack | 首期留作内部创作；若买家确有编辑需求，再定义协作包 | 工程真实 Live 还原待验，第三方原始切片的再分发不能默认包含 |

商品 WAV 建议保留真实制作采样率的 24-bit 版本，不靠升采样包装音质；最终服从所选后台规格。分轨统一起点、长度与线性增益，提供供混音的参考混音；不要把各轨单独归一。技术门槛用解码、帧数、削波、哈希与求和残差验收，音乐门槛用买家真实人声叠录验收。

**价格只作为试验方案：** 国内可讨论基础 ¥99 / 分轨 ¥299，海外可讨论 $29 / $79；这些是待用户确认的起始假设，不是行业均价、已验证支付意愿或已发布报价。第一轮先固定价格观察买家反应，避免同时更换风格、价格、授权和渠道。首期不设独家买断：独家能授予什么取决于实际拥有的权利和既有授权，不能承诺独占第三方老录音或音色库。

合同至少对应 beat ID、音频版本/哈希、买卖双方、日期/订单、文件清单、可制作的歌曲与使用场景、地域/期限/用量、发行/视频/演出范围、署名和分成、第三方内容声明、禁止转卖素材、Content ID 约定、升级和退款/争议处理。按具体平台模板和素材许可确认后再形成可签文本；本研究清单不代替最终合同审查。

## 采样与 AI：商品准入的具体边界

1. **每个来源独立核验。** Citizen DJ Jazz 页说明馆藏公版可商业改编，并解释依据美国法律进入公版；它同时提示隐私/形象权。这是来源证据，不是所有国家、所有用途均已清权的证明。歌曲与录音、地域和实际使用片段须逐项核对。[官方说明](https://citizen-dj.labs.loc.gov/loc-jukebox-jazz/use/)
2. **Ableton 原创作品与素材包有区别。** 官方允许 Live 持证用户把 Core Library/Packs 内容用于加入其他材料且显著改编的原创作品；商业采样产品需另行书面许可，Demo Songs 不能用。现有 ChopRack 或孤立库内样本不可顺手作为商品赠品。[Ableton 条件](https://help.ableton.com/hc/en-us/articles/209768885-Commercial-Use-rights-for-Live-content)
3. **平台也有自己的样本条件。** BeatStars 上传帮助要求样本 100% royalty-free，禁止未授权素材，使用第三方 loop/sample 仍要在元数据披露/署名。我们的历史采样需判断具体适配，不能因为能下载或能上传就标成已准入。[上传要求](https://help.beatstars.com/hc/en-us/articles/1260802609630-How-Do-I-Upload-Tracks)
4. **出售许可与 Content ID 登记分开。** YouTube 要求参考音频在主张地域具有独占权，非独家素材、公版内容、production loops 等不能作为相应参考。Airbit 的 Content ID 准入另列 AI 音乐等限制；这不能外推成 Airbit 全站禁止一切 AI 辅助作品。首批建议不登记 Content ID，也不向买家许诺可独占登记。[YouTube](https://support.google.com/youtube/answer/2605065) · [Airbit Content ID](https://help.airbit.com/hc/en-us/articles/24166112925465-What-Can-I-Submit-For-Content-ID)
5. **AI 用途要如实区分。** 当前项目是代码/AI 辅助策划、真实音频切片与编排；本轮未使用整曲生成模型或克隆歌手。BeatStars 有自愿加入训练的 AI 项目，但这不是任意第三方 AI 输出都可出售的保证，也不是本项目已同意训练授权。三家实际上传时的 AI 标识、模型输出商业条件和审核仍需核验。[BeatStars AI FAQ](https://help.beatstars.com/hc/en-us/articles/49108589350811-BeatStars-AI-FAQs)

某条素材无法覆盖目标用途时，替换该层或先保留私人草稿；不能只在商品页写“版权由买家负责”跳过来源问题。能售卖原创建成的歌曲，也不自动证明可以再分发孤立样本。

## 从发现到复购的最小闭环

```mermaid
flowchart LR
    A[30–45秒展示 / 定向试听] --> B[完整试听 / BPM / 用途]
    B --> C[买家写16小节 / 选许可]
    C --> D[平台确认付款]
    D --> E[约定音频 + 分轨 + 合同]
    E --> F[下载可用 / 到账核对]
    F --> G[录歌反馈 / 后续需求]
    G --> H[下一版或下一首]
    H --> A
```

获客第一步是能写歌的目标人群。国内候选为现有音乐人关系、制作交流与短视频展示；海外候选为英文风格/BPM 标注的试听内容与平台发现。每首先制作一个有明确入口的展示片，所有入口指向同一商品/试听页；不假设上传后平台自动给流量。对外联系和发布须在确定对象/渠道与内容后执行，本轮未发送。

付款和合同尽量用平台现有功能；不用私人转账加手动压缩包作为默认产品流程。Airbit 官方提供付款后下载与合同，并允许在订单详情查看下载历史，可用于交付核对；下载并不等于买家成功导入和使用。[订单下载记录](https://help.airbit.com/hc/en-us/articles/24166220571929-How-Do-I-Check-If-The-File-Has-Been-Downloaded-After-Purchase)

初期用一张私有记录表即可：`beat_id/version → channel/listing → listener/trial → license_version/order → paid → delivered → downloaded/usable → settled → feedback`。区分付款成功与卖家已到账，记录币种、金额、平台/支付费、退款和净收入；不把买家个人资料放进 Git。只使用平台允许取得的数据，暂无已核验的卖家上传/订单 API。

反馈至少记录：谁在什么版本哪个时间点遇到什么问题、是否实际录了 16 小节、选了哪档或没买的主要原因。试用无反馈保持“未知”。获准联系后可在交付后 3–7 天询问是否能用及下一首需求；不默认订阅营销邮件。

## 一轮试验的执行卡草案

建议后续单独选择“首个可试唱商品草稿”，不要把 R06 调研通过当成批量上架授权。

| 阶段 | 执行方与投入建议 | 交付/退出条件 |
|---|---|---|
| 第 1 天：定买家与作品 | 用户约 10–15 分钟选择国内/海外及一首候选；执行方整理当前账号可行性 | 一个市场、一首版本、一个渠道候选；账户或内容条件不成立则先解决，不购买多家会员 |
| 第 2–3 天：可用与可交付 | 执行方做两版、来源表、文件包、合同字段和页面草稿；用户听最关键 30–60 秒 | 16 小节可试唱、两版关系明确；来源范围未清楚则停在私人草稿 |
| 第 4–7 天：小规模验证 | 在对象、分享范围获准后，邀请目标音乐人试用；用户最终确认商品、授权、价格再发布 | 目标 10 次有效试听、3 次真实试唱、1 次真实付费且交付可用；不足如实记录 |

上述数字是本项目试验门槛，不是平台平均转化率或收入承诺。没有足够目标听众时先改展示/触达；有试听却没人愿意录歌时先改音乐与使用空间；愿意试唱却不购买时再核对许可、价格、支付阻力。小样本不能把原因直接归咎于音乐不好听。
