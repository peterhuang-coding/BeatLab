## 现在可以做什么

- 在播放器下抓取时间，选「太嘈杂／重复／鼓组／过渡／喜欢／其他」，写原话并保存。刷新后仍在，点已保存时间能回听该处。
- 笔记绑定 run_id 与实际音频 SHA256，支持多条记录、网络重试幂等、旧音频版本拒绝；保留旧版本记录。存于媒体根的 listening-notes.sqlite，已排除 Git。
- 展开来源区块，逐声部查看记录的原始文件名、来源网址、许可说明和哈希。只展示实际声部；歧义与缺失明确显示，不从同名素材推断匹配或商业许可。
- 原句/solo 和声部音量调整折叠保留；现有增益反馈仍实际生成不可变子版。
- /media 支持单区间 206、不可满足区间 416 与分块传输；修复编码目录穿越和外部 symlink 逃逸。畸形、多区间及零后缀请求忽略 Range，返回完整200，不声称支持多区间。

## 验证

- 原基线194项；最终272项 unittest，13.887秒，全部通过。新增笔记19、来源30、媒体29项。
- 浏览器保存1.25秒和2.5秒两条合成笔记、刷新、跳转、捕获时间均验证；HTML样式文本按原话显示。旧声部反馈实际生成 keys −6dB 子版。
- 真正的浏览器错误：修复前音频已buffer 4秒，但seekable为[0,0]，点1.25秒返回0；修复后seekable[0,4]且跳转正确。HTTP bytes=44-99实际返回206、56字节。
- 首次全套合跑暴露测试全局目录污染与 pipeline 模块同名问题；修正测试隔离/导入后重跑全套通过，不拿单包绿灯代替整体通过。
- 16份已有主混音（full_mix.wav与beat.wav）的 SHA256 与mtime保持。测试笔记和增益子版只在隔离合成目录；真实作品没有写入假听感。
- 三段真实小样页面核验：Applause Machine 26轨／10条匹配；No Curtain Call 22轨／7条匹配；Pocket Sun 25轨／11条匹配。剩余主要为翻采切片到原句的直接关联未补齐，页面如实显示缺失。这里匹配的是清单记录，不是重新核验来源音频或许可。
