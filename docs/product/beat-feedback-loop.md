# 从十首试听到可售作品

当前批次 MUSIC-TEN-20260927：《城市余像》，目标10首约一分钟的真实翻采草稿；当前01–06已交付，07–10待额外续修决定。商业化是最终目标，首轮先验证哪些音乐值得用户保留；工作标题与叙事可随试听调整。

## 用户反馈的五个刻度
每项1表示明显不满意、3表示有潜力但需修改、5表示愿意保留当前表现。空白就是未评，不自动填中间分。

- 律动：鼓与Bass是否让人想跟着点头。
- 采样记忆点：能否记住一句、一个节奏或声音关系。
- 变化：段落变化是否有意思，同时保持主题。
- 清晰度：主次是否清楚，有没有嘈杂或低频挤压。
- 人声空间：作为beat是否给说唱/唱歌留出空间。

保留、待改、不要分别记录，不用平均分替用户做决定。先挑最想继续的2–3首；也可以全部不选。时间点笔记写“哪里/想改什么/什么别动”，例如“0:24回答句重复，换不同内容；前半段和鼓Bass保留”。不需一次把所有维度评完。

## 自动恢复与修订边界
试听页把track_id、version、原混音SHA和用户输入一起保存到本批feedback.json；重复保存相同内容不重复执行任务。分数用于理解偏好，不能直接当音乐好坏的真值或自动扩写授权。夜班比较该文件与ten-beats.json的feedback_last_consumed_sha256，未变化则静默。

新反馈先关联实际音频版本，提取明确的目标段落、目标声部和锁定范围。明确的修改要求按原闭环执行：保留父版，有限候选，保护鼓/Bass和非目标区间，真实音频检查，音量匹配对照，等待用户Keep。描述含糊时只问冲突点，不猜测重做全曲。用户在DAW的修改要用新导出或工程保存状态核验后作为父版，不能监视未保存活动工程并覆盖。

## CC与主代理的分工
CC优先承担有界的选源筛选、切片算法、明确编排、测试和交付工具。真实私有音频默认留本地；给CC的是最小公开/合成接口，或已明确可外发的素材。主代理核验来源、实际音频、保护条件及采纳结果。同波最多两路，未知执行不重发，任务ID跨恢复固定；不承诺无限额度。

后台供给按当前作品缺口找音源，先搜现有库；每批限制来源范围/下载数量/体积，去重、核对用途、保留出处及双哈希。收藏的数量不是好句数量。既有crate工具可复用，当前10首已有素材足够，未新增无限抓取任务。

## 选中曲目后的交付关卡
1. 用户选曲，确定扩写长度与用途，保留满意段落。
2. 修订、完整编排和实际试唱，检查记忆点、主歌空间、过门与结尾。
3. 独立验收来源使用范围、音频/分轨/MIDI/工程；Live实际打开保存与回渲染单列。
4. 选定平台与成品后，先准备可审阅的商品资料和本地交付校验，再跑具体发布流程。当前10首未上架、无支付或对外联系。
